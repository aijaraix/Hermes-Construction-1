# HERMES CONSTRUCTION — AGENT ROSTER (125+ LOGICAL SPECIALIST ROLES)

## Overview
HERMES Construction defines **125+ specialized logical agent roles** across 16 core disciplines. Rather than executing 125 LLM instances continuously, roles are activated dynamically based on project location, building type, floor/room scope, active trade sequence, and inspection needs.
