# HERMES CONSTRUCTION — PHASE 3.18 MASTER PLAN
## Autonomous Subject-Matter Expert Academy, Specialist Practical Sandboxes, Qualification Gates, and First Autonomous Build

### Executive Overview
Phase 3.18 establishes the full autonomous learning and execution pipeline for HERMES Construction. Moving beyond static rules and simple retrieval, Phase 3.18 equips specialist trade agents, discipline managers, and quality inspectors with domain-specific master curricula, live source ingestion, specialist practical sandboxes, adversarial qualification gates, and autonomous build execution.

---

### Sequential Phase Architecture

#### Phase 3.18A — Subject-Matter Expert Academy & Continuous Knowledge Ingestion
- **Roster & Governance**: Audit of all active specialist agent contracts, discipline managers, and executive leads (`HERMES-PRIME-ORCHESTRATOR`, `HERMES-LEARNING-EXECUTIVE`, `CONSTRUCTION-KNOWLEDGE-DIRECTOR`).
- **Domain Boundaries & Curricula**: Explicit machine-readable master curricula for every role detailing foundational physics, Florida Building Code 2023, ACI, ASCE, NEC, and OSHA standards.
- **Source Plan & Document DB**: Automated ingestion from authoritative primary sources (FEMA, DOE, NIST, FBC, ACI, IEEE, Manufacturer Specs).
- **Quota-Aware Execution**: Robust background document parsing, chunking, hashing, and indexing that continues continuously even if LLM reasoning provider quotas are rate-limited or exhausted.
- **Unattended Heartbeat**: Background ticker executing continuous learning, ingestion, chunking, testing, and manager reviews without requiring manual user intervention.

#### Phase 3.18B — Specialist Practical Sandboxes & Manager Training
- **Specialist Sandbox Environments**: Isolated digital simulation environments for structural, thermal, hydraulic, electrical, and spatial design.
- **Deterministic Math Engine Verification**: All agent proposals tested against closed-form physical formulas (e.g., ACI 318 moment capacity, ASCE 7 uplift pressure, NEC voltage drop).
- **Manager Review System**: Discipline managers review specialist submittals against hidden validation rules, code compliance thresholds, and cost/schedule delta limits.

#### Phase 3.18C — House #1 Capability Matrix & Qualification Gate
- **Required Capability Matrix**: Comprehensive matrix covering structural foundation, timber frame, envelope thermal/moisture barrier, MEP branch distribution, and final commissioning.
- **Adversarial Inspector Gym**: Independent quality inspectors inject defective edge cases to test agent detection, repair ticket issuance, and re-inspection workflows.
- **Readiness Threshold**: Mandatory >= 85.0% certified core House #1 competency before advancing to active autonomous construction.

#### Phase 3.18D — First Integrated Autonomous House Build
- **End-to-End Build Execution**: Autonomous orchestration of House #1 design, BIM component placement, BOM pricing, trade sequence coordination, inspection sweeps, and closeout certification.

---

### Key System Guarantees
1. **Never Fake Expertise**: Agents must be explicitly assigned `UNTESTED`, `INGESTING`, `KNOWLEDGE_TESTED`, `READY_FOR_SHADOW_WORK`, or `READY_FOR_CONSTRUCTION_WORK` based strictly on verified evidence.
2. **Data Truth & Provenance**: Every knowledge assertion and calculation must reference a verifiable source document chunk and checksum.
3. **Continuous Unattended Autonomy**: System learning and ingestion run continuously via background server heartbeats regardless of browser focus or session state.
