# HERMES MASTERY CERTIFICATION
## Verification Standards, Scope Limitations, and Certification Governance

### Overview
Mastery Certification in HERMES ensures that no agent operates in live construction without verified proof of competence. Certification is granular and explicitly bound to valid scope parameters (jurisdiction, climate zone, building type, material system).

---

### Certification States

1. `UNTESTED` / `DEFINED`
   - Agent contract exists in registry but curriculum has not been fully ingested or tested.
   - Prohibited from submitting BIM modifications.

2. `CURRICULUM_ASSIGNED` / `INGESTING`
   - Primary source documents fetched, parsed, and chunked into memory.
   - Agent active in Academy study cycles.

3. `KNOWLEDGE_TESTED`
   - Agent passed scenario-based written evaluations and citation accuracy tests ($>= 90\%$).

4. `READY_FOR_SHADOW_WORK`
   - Passed specialist sandbox deterministic math tests and received Discipline Manager review signoff.
   - Permitted to run shadow work simulations alongside benchmark solutions.

5. `READY_FOR_CONSTRUCTION_WORK` (Certified Master)
   - Passed shadow work benchmarks, zero critical inspection defect history, and full manager approval.
   - Authorized to participate in live autonomous construction builds.

---

### Certified Scope Boundaries
Certifications are explicitly tagged with operational limits:
- **Jurisdiction**: e.g., Florida (FBC 2023 High Velocity Hurricane Zone).
- **Building Type**: e.g., Single-Family Residential (IRC / FBC Residential).
- **Climate Zone**: e.g., Zone 1A / 2A (Hot-Humid Marine).
- **Scope Limitations**: e.g., "Shallow spread footings on soil bearing capacity >= 2000 PSF only; deep pile foundations require professional structural engineering escalation."
