# HERMES HOUSE #1 CAPABILITY MATRIX
## Core Construction Requirements, Trade Disciplines, and Readiness Gate Criteria

### House #1 Profile
- **Building Type**: Single-Family Coastal Residence (2-Story)
- **Location**: Tampa / St. Petersburg, Florida (Climate Zone 2A)
- **Jurisdiction**: Florida Building Code 2023 (Residential) + ASCE 7-22 (Wind Load $150\text{ mph}$)
- **Dimensions**: $32\text{ ft} \times 44\text{ ft}$ Footprint, 2 Floors ($2,816\text{ sq ft}$)
