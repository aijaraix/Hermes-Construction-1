# HERMES 3D Digital Twin & 4D Scrubbing

## 3D BIM Viewer
Built with Three.js WebGL rendering, the digital twin viewer supports:
- Interactive orbit, pan, zoom controls.
- Trade system filters (Structure, Plumbing, HVAC, Electrical, Envelope).
- Inspection state heatmaps (Passed = Green, Open Failure = Red, Repaired = Blue).
- 4D Construction Timeline scrubbing from Day 1 to Day 30+.
- Intermediate version snapshot playback (V001 Site -> V002 Foundation -> V003 Structure -> V004 Envelope -> V005 MEP -> V006 Passed Inspection).
