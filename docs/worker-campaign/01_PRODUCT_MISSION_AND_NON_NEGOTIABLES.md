# Product mission and non-negotiables

AEDRYX is the public/product brand of Hermes Construction: a living construction academy and construction operating system. The world remains the product, with professional CAD/BIM clarity rather than a separate game demo.

Canonical flow: COMMAND → EVENT → STATE → WORLD → OBSERVATION → VALIDATION → NEXT ACTION. Renderer, imported BIM, AI outputs and public datasets do not create an independent canonical truth store.

Preserve FND-01 stable identity/revision/units/frames and FND-02 evidence, authority, derivation, reality and claim-state separation. Preserve the Academy House vertical slice, project switching, run/step/reset, selection and view-only replay. Deterministic code owns geometry, math, quantities, transforms, collision and scheduling calculations where supported. No local XYZ gains a fabricated geographic SRID.

Use truthful labels: PHYSICALLY VERIFIED; IMPLEMENTED — NOT PHYSICALLY VERIFIED; PARTIAL; SIMULATED; BLOCKED; NOT IMPLEMENTED. Missing evidence is UNVERIFIED. Code/test success cannot imply physical construction, professional/AHJ/CO/legal approval, browser acceptance or production acceptance. Internal and simulated outcomes remain identifiable.

No conceptual reset, renderer replacement, custom IFC/GIS parser, duplicate world, unnecessary infrastructure, universal physics, robotics/actuation, provider deployment/model download, supplier purchasing or broad cleanup. Preserve runtime files by exact bytes; test only disposable source copies.
