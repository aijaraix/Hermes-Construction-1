# Browser / visual QA protocol

Use an isolated, long-lived copy of the exact accepted/candidate Node/Express application with its normal React/Three.js/WebGL world. Do not replatform Hermes merely for a preview. Use existing authorized resources without new recurring infrastructure or production deployment.

For every evidence artifact record source head/candidate hash, requested project ID, independently observed API project ID, visible world identity, attempt, checkpoint/event, camera/view, viewport and timestamp. Verify browser identity against actual API requests and visible world independently: the existing backend parity test sets IDs from one source and cannot prove this.

Capture empty land; mobilization/equipment/materials; foundation/framing; roof/openings/enclosure; MEP; close-in/finishes/completed residence. Exercise architectural/construction/X-ray/system isolation, walkthrough, section, replay, logistics, actor payload and selected-component provenance. Check console/network errors, keyboard input guards, overlays, desktop/mobile controls and pointer accessibility.

Compare visible dimensions/locations with canonical units/frames, including a known one-metre segment and frame transform. Confirm reset creates the correct attempt and replay is view-only without history mutation or invented approval.

HX-01: before/after desktop/mobile; persistent world mount and canvas size through workspace switching; one primary overlay; inspector closed by default; project/run/step/reset/selection/replay preservation.
HX-02: correct component/material/actor/equipment inspector; supported focus/isolate/hide; truthful quality/authority; last-seen isolation by project+attempt; compact timeline and reset/deleted selection.
HX-03: canonical material counts/cost, calculated schedule only, evidence-supported logistics and bridges. Do not remove duplicated Developer/System project tools until replacements physically pass.

FND-04: reference and actual imported model load, selection/isolation/hide, supported section/measurement, canonical identity/frame projection and real parse-failure surface without fake fallback geometry.

Report unavailable faithful browser/WebGL acceptance as BLOCKED / UNVERIFIED. A screenshot of an error page is evidence of a blocker, not product acceptance. Local HTML screenshots or a disconnected scene are not substitutes.

The long-material route flag is a fixture behavior, not a general swept-volume solver. General spatial proof requires future varied payload size/orientation, doorway/turn space, obstacles and independently computed passable/blocked cases; do not expand this campaign silently.
