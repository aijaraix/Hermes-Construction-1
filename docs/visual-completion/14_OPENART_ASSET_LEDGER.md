## Integration rules

Before integrating:
- verify generation completed successfully;
- visually inspect asset;
- reject obvious physical nonsense;
- preserve correct aspect/crop;
- optimize delivery format/size;
- add descriptive alt text;
- do not bake marketing copy into the image;
- do not imply the image is a real customer project or live robot deployment.

If a generated image is visually weak, replace only that asset; do not block unrelated campaign stages.
